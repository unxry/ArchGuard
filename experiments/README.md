# Experiment workspace

Architecture-only experiment: Static / Graph / LLM / Hybrid. No experiment runner, dataset,
ground truth or results are supplied in foundation. Contract examples belong only to tests.

Read `docs/experiments/EXPERIMENT_PROTOCOL.md` and `REPRODUCIBILITY.md` before adding artifacts.
Dataset, ground truth and result payloads are ignored by default; intentionally version approved
research data with an explicit provenance/versioning decision. Never silently promote UI demo data.
