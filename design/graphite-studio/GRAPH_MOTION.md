# Graphite Graph Engine · motion specification

SVG engine из P039 сохранён и расширен в локальной копии. Новых graph/animation библиотек нет. Все paths задаются геометрией source → target. Анимация показывает направление статической зависимости, **не исполнение кода**.

| Состояние | Поведение | Длительность / бюджет |
|---|---|---|
| Mount / смена плотности | Узлы проявляются по очереди; геометрия сразу доступна клавиатуре | 420 ms, stagger 18 ms с пределом 160 ms |
| Выбор узла | Amber outline, подсветка соседей и incident paths, обновление selection bar и dossier | Цвет 180–250 ms; акцент 500 ms |
| Hover / focus | Раскрываются incident edges или выбранная связь | Без RAF, CSS transition |
| Direction replay | До четырёх световых головок и следов по настоящим SVG paths | Конечное окно 4000 ms, цикл 1150 ms, фаза 160 ms |
| Precision trail | Короткий ограниченный след | До 26 SVG units |
| Cinematic trail | Более выразительный след без постоянного свечения | До 56 SVG units |
| Camera | Кубическое ease-out для focus/fit | 420 ms; zoom 0.5–3.2 |
| Dossier | Короткий вход с translate/opacity | 450 ms |
| Reduced motion | Переходы и layout entry отключены, выбор/камера применяются сразу | Нет pulse RAF |
| Hidden tab | RAF отменяется; elapsed сохраняется; entry ставится на паузу | Возобновление только оставшейся части окна |
| Dispose | Cancel RAF, camera, WAAPI; AbortController отключает DOM listeners | Каждый unmount / render |

## Геометрия и масштаб

Базовый SVG 1040×620. Узел 208×64. Precision: три ортогональные колонки. Cinematic: три смещённые плоскости, сохраняя направления и идентичность узлов. Cubic paths соединяют границы узлов; обратные и длинные рёбра имеют собственные дуги. Направление головки вычисляется через `getTotalLength` и `getPointAtLength`; след использует тот же `d`, длину и offset. Тест проверяет совпадение координат головки с окончанием следа.

40/216 узлов сначала агрегируются по шести доменам. Раскрытие домена показывает реальный subset; более 24 узлов домена разбиваются на страницы до 18. Это стабильная группировка по данным, не force-directed clustering и не аналитическое открытие архитектуры. Демонстрационные добавленные узлы явно синтетические.

На мобильном небольшая карта начинается с 235% для читаемых подписей; выбранный узел получает центрирование. «Вместить» возвращает общий вид. Полный список модулей остаётся доступным без точного попадания по SVG; на малом масштабе вторичная детализация скрыта.

## Доступность

Nodes и edges доступны Tab / Enter / Space, между узлами работают стрелки; полный identifier находится в accessible name и досье. Список модулей — альтернативный способ выбора. Видимое направление не зависит только от анимации: остаются arrowheads, выбранный путь и текстовая легенда. Переключение motion сохраняется отдельно от P039. Полное имя длинного модуля читается в досье, даже когда подпись карты сокращена.

## Проверка и ограничения

Реальные Chromium checks, screenshots и WebM находятся в `previews/`. Отчёт содержит 4× CPU throttle, количество кадров, p95 frame interval, long tasks, CLS и heap после 20 циклов mount/unmount. Это измерения конкретного браузера и машины, не гарантия FPS на любом устройстве. Hidden-tab проверка отправляет visibility event с управляемым `document.hidden`; это контролируемая проверка lifecycle, не измерение поведения всех ОС в фоне.

При переходе на production отдельно нужны большие импортированные проекты, профилирование целевых браузеров, полноценная accessibility-проверка и выбор постоянного инспектора. Текущий интерфейс намеренно ограничивает число видимых узлов; весь raw artifact сохраняется.
