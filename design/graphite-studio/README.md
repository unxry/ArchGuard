# ArchGuard · Graphite Studio / P039.1

Интерактивное исследование дизайна на основе P039 V2 `4a73d9d`.

Откройте **[comparison.html](comparison.html)**: два направления, реальные снимки Chromium и видео. Прямые входы: **[Precision](precision.html)** и **[Cinematic](cinematic.html)**. HTML работает с диска; переключение варианта сохраняет текущие данные и выбор. Свежий профиль запускается на русском, EN доступен в шапке. Последний выбранный язык сохраняется локально.

Для HTTP-просмотра из корня репозитория:

```sh
node design/graphite-studio/dev-server.cjs
```

Адрес: `http://127.0.0.1:8781/comparison.html`. Сервер доступен только локально. Дополнительный backend не нужен. Никакого деплоя или загрузки исходного проекта на внешний сервис.

## Поставка

Три интерактивных семейства экранов: обзор проекта, Architecture Atlas, Security / Findings. Models и Runs оставлены как вспомогательные инструменты P039 с явной пометкой; их полноценный редизайн не начат. Все состояния демонстрации синтетические. Импорт CLI JSON сохраняет исходные ограничения и не смешивает данные с демонстрацией.

Рекомендация: **Cinematic**. Широкая сцена делает направление зависимостей заметнее, тёплый проектный контекст и досье разгружают тёмную среду. Precision подходит для пользователей, которым важнее постоянный боковой инспектор и компактный реестр. Окончательный выбор принадлежит пользователю.

## Проверка

`tests/browser.cjs` использует Playwright из доступного окружения. Он требует запущенный локальный сервер; `PREVIEW_URL` переопределяет адрес. Тест проверяет оба направления, RU/EN, импорт публичных CLI fixtures P039, клавиатуру, графовые состояния, motion lifecycle, три ширины, performance и записывает настоящий WebM. Собственных зависимостей runtime и сборщика нет.

`foundation.css` и неизменённые модули скопированы из P039 для автономного прототипа. `studio.css`, `tokens.css`, `src/studio.js` задают исследование дизайна. В локальных копиях `src/graph.js`, `src/app.js`, `src/core.js` изменены только presentation, motion, навигация и отдельный namespace настроек. Оригинальный каталог P039, backend и scientific core не изменены.

Рабочая ветка: `design-lab/archguard-graphite-studio`. Только `design/graphite-studio/`. Не merge. Полная production-миграция начинается после визуального выбора.
