## Классификация

`API_EXPOSED` — действующий HTTP route. `CLI_ONLY` — CLI + library, без HTTP. `REAL_INTERNAL_ONLY` — вызываемая библиотека/контракт без пользовательского scan route. `RESEARCH_ONLY` — исследовательская поверхность, не production journey. `PROPOSED` — отсутствующий адаптер/процесс. `UNAVAILABLE` — обещание, которое текущий код не поддерживает. Наличие UI-карточки означает discoverability, а не интеграцию соответствующего анализатора.

## Семантические инварианты

- **Architecture:** actual IAM ≠ target specification ≠ discovered hypothesis. ARCH001–005 require explicit rules and grounded evidence; ARCH101–105 structural candidates and ARCH201–205 semantic candidates remain distinct. Static imports/calls are not runtime traces.
- **Hybrid:** preserve deterministic Finding IDs and configured severity. Uncalibrated candidate has no numeric confidence; structural score is a separate policy output. Full live remote Hybrid and general calibrated semantic confidence are unavailable.
- **Security:** finding status, severity, evidence strength, execution coverage, flow uncertainty and rule-scoped outcome are six different dimensions. CONFIRMED_PATTERN is not proof of exploit; NOT_APPLICABLE is not safe. V2 zero findings stays partial. TS SEC005 remains contract-only/unsupported.
- **SEC catalog:** SEC001 secrets; SEC002 SQL; SEC003 command; SEC004 traversal; SEC005 deserialization; SEC006 SSRF; SEC007 XSS; SEC008 weak crypto; SEC009 insecure randomness; SEC010 unsafe dynamic execution. Framework packs and rule-specific guards have narrow preconditions/invalidators, not universal framework coverage.
- **Completeness:** whole repository safety cannot be inferred from a complete path, one scoped certificate, health=ok, parser success or zero findings. Import structural validation does not prove artifact authenticity.

## Контракты offline result import

| Kind | Реальный shape / identity | UI boundary |
| --- | --- | --- |
| Graph | `GraphAnalysisResult`, nodes `graph.nodes`, edges `graph.edges`, proof `edges[].proofs`; root metrics/findings/candidates; schema 1.0 | Shared version 1.0 is insufficient discriminator; validate references/counts/locations |
| IAM | `ArchitectureModel` from `--output`; `IAMBuildResult.iam` from stdout `--json` | Formats differ; preserve project identity and quality metadata |
| Static check | `StaticConformanceResult` root findings/classification/specification_summary, no analysis_kind/full graph | Display standalone findings; don't fabricate graph |
| Composite check | `analysis_kind=architecture_check`; static_result + **GraphConformanceResult** graph_result | GraphConformanceResult is not GraphAnalysisResult |
| Discovery | `analysis_kind=architecture_discovery`; `graph` is GraphAnalysisResult, nodes at `graph.graph.nodes` | Actual graph plus hypotheses in one artifact |
| Context | `context_schema_version=1.0`; selected_nodes/fragments refs/evidence; no project/IAM hash | Standalone context; reject source pack by default; no unproven snapshot join |
| AI | targets/manifests/request_metadata/candidates/invocations; result schema 1.0 | Live invocation IDs/latency not byte-stable; not a confirmed-Finding result |
| Hybrid | `result_schema_version=hybrid-analysis-v1`; cases/evidence_bundles/features/decisions; root confirmed_finding_ids | No root full graph or full findings; ordered binding and proof rules matter |
| Security | `namespace=SEC`, analyzer_version, SecurityFinding[], rule sets/diagnostics/analysis_metadata, guarantee=false; optional SecurityReportSection | Separate wire schema from generic ARCH Finding; coverage version-aware; report effectiveness=false |

## Проверки и нерешённые интеграции

CLI fixture проверен реально: авторские 3 TS modules / 4 imports → graph COMPLETE (3 nodes, 4 edges, 4 proofs, 1 cycle observation) и static check NON_CONFORMANT (1 ARCH001 HIGH). Pydantic validation, relative locations, shared IAM identity и byte-identical repeat выполнены; см. [fixture receipt](tests/fixtures/README.md). Security audit отдельно подтверждает model-only result/report round-trip; анализаторы Security не запускались.

Browser import этого реального fixture и visual/interaction acceptance — отдельная проверка, **не подразумевается** CLI receipt. Актуальное покрытие и выполненные проверки: [coverage report](UI_CAPABILITY_COVERAGE_REPORT.md). Production integration требует run/result/source endpoints, identity/auth, persistence, budgets/cancellation и API contracts; ни один из них не создан интерфейсными карточками.

`src/catalog.js` — индекс discoverability C01–C15, не source-of-truth путей. В просмотренном срезе часть коротких source refs указывает на прежнюю структуру (`repository/service.py`, `parsing/service.py`, `iam/builder.py`, корневые graph/conformance/discovery/ai/hybrid). Авторитетные пути приведены выше и в глубоких audits; каталог нужно синхронизировать с ними.
