# STRATA / Systems Studio

В P038 атлас выглядел как отдельное исследование. V2 становится рабочим местом: проект и происхождение результата постоянно видны, соседние пространства отвечают за разные вопросы. Карта получает большую площадь, dossier становится инструментом чтения, а заголовки — компактнее после первого входа.

Сохраняем mineral-dark, тёплую бумагу evidence и lime. Вводим глубокий blue-grey для каналов Security, терракоту для доказанных нарушений и открытый контур для неизвестного. Serif остаётся только в editorial heading и dossier; взаимодействия и длинный русский текст используют системный sans. Сетка и направляющие — инженерные, без glassmorphism, чрезмерного glow или декоративных KPI cards.

Оригинальность — в смене масштаба знания: system clusters → module → relationship → evidence → исходная строка. Анимация кратко проводит взгляд по реальной геометрии отношения. Она объясняет статическое направление, не симулирует исполнение кода.

Главная самостоятельная продуктовая идея — **граница знания как первоклассный объект**. Run provenance, unknown resolution, uncalibrated candidates, incomplete Security и unavailable AI занимают осмысленное место в UI. Это делает приложение полезным даже offline.
