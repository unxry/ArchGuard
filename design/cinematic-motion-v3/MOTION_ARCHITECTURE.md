# Motion & spatial architecture

## Единая система

SVG 1280×740 отвечает за геометрию; WAAPI — за сборку и панели; один requestAnimationFrame — за до четырёх световых импульсов. Camera использует сохранённую модель pan/zoom P039. Отдельная короткая интерполяция параллакса завершается после достижения цели. При бездействии циклов нет. Canvas/WebGL/Three.js не добавлены.

`Motion.Scope` владеет WAAPI animations, поддерживает pause/resume, отмену и освобождение. Каждый graph render заменяет старый scope; dispose освобождает scope, RAF, camera, parallax и AbortController. Reduced motion отменяет также camera и parallax RAF. Глобальная реакция на hidden/reduced распространяется также на evidence и shared transitions. Настройки и locale хранятся в отдельном `ag-cinematic-v3-*` namespace; исходные P039/P039.1 предпочтения не меняются.

## System assembly

Состояния: assembling → tracing → resting. На reduced/off — сразу resting.

| Фаза | Что объясняет | Параметры |
|---|---|---|
| Layer emergence | Группировка архитектуры по слоям | 800 ms, stagger 160 ms, вертикальный вход до 75 SVG px |
| Module placement | Принадлежность модулей слоям | 680 ms, задержка 450 + 40×index ms |
| Edge reveal | Истинные отношения между готовыми модулями | До 24 видимых paths, 1050 ms, начало 1050–1330 ms |
| Dependency light | Направление известных статических связей | До 4 путей, конечный проход и затухание |
| Rest | Система доступна для исследования | Нет постоянной пульсации/RAF |

Сдержанный режим: без пространственного перемещения, сокращённая сборка ~500 ms, до двух потоков с коротким следом. Первичная сборка связана с идентичностью dataset + view + density + cluster + page. Смена языка/малого фильтра не повторяет тяжёлую сцену. Явный replay всегда доступен. Новый импорт визуализирует уже полученные результаты; UI не показывает фиктивный процент анализа.

## Volumetric architecture

Каждый слой — замкнутая наклонная платформа: верхняя плоскость, боковая глубина 20 SVG units, контурный rim, контактная тень и локальный ambient gradient. Три платформы смещены по высоте и горизонтали. Модули — скошенные восьмиугольные корпуса с материалом, фаской и тенью. Labels не наклоняются и остаются читаемыми. На меньшем desktop скрывается повторяющаяся подпись типа; идентификатор и заголовок слоя сохраняются.

Освещение иерархично: холодный нейтральный материал → тёплая грань выбранного слоя → amber path → краткая активация цели. Coral отличает связь с finding, но не повышает статус доказанности. Небольшой параллакс перемещает весь мир (узлы и paths вместе) максимум на ±4/±2.5 px и затухает до остановки.

40/216 узлов сначала агрегируются по имеющимся доменам в объёмные кластеры. Раскрытие даёт реальный subset, более 24 элементов домена разбиваются на страницы до 18. Это представление данных, не новый алгоритм architecture discovery.

## Living light connections

Head и trail используют один `d`. Положение головки — `getPointAtLength(t × getTotalLength())`; trailing dash заканчивается в той же координате. Обычный путь получает amber, finding path — coral. Затухание применяется как computed opacity, не только SVG attribute, чтобы CSS старой версии не блокировал fade.

Один проход длится 1350 / speed ms. Скорости: 0.7, 1, 1.4. При обычном replay фаза между путями — 130 ms. Для bounded chain пути включаются с перекрытием 72% длительности. Головка достигает только фактического target; цикл/повторный узел обходится, максимум четыре связи. Target illumination не означает выполнение модуля. Данные и статусы не меняются.

Camera focus вычисляет bounds выбранной цепочки, вписывает их в сцену с ограничением 1.55×. Движение 420 ms ease-out. Выбор слоя даёт умеренный 1.15× focus. Fit восстанавливает всю видимую карту. Последовательности не добавляют узлы/рёбра вне текущего dataset/subset.

## Пространственные переходы

Overview → Atlas / обратно: inert SVG snapshot переносится между реальными bounds сцены за 680 ms; под ним появляется действующий новый graph. Геометрия и выбранный ID совпадают. Клон имеет собственные IDs, не перехватывает события и удаляется после перехода или при следующем render. Навигация и state update остаются синхронными. Rapid navigation отменяет старый bridge.

Module → related finding: краткая контекстная метка движется от выбранного узла к evidence heading **только если finding действительно содержит этот node ID**. Для независимого Security-примера такая связь не выдумывается.

Evidence: шаги раскрываются с задержкой 170 ms, source входит с отдельной оси. Клавиатурный/мышиный выбор известного proof step подсвечивает конкретную строку только при совпадении path и line с открытым evidence. Unknown step сохраняет пунктир и не подсвечивает строку как доказанную. Certificate details проявляются внутри раскрываемого документа; текст scope не меняется.

## Ограничения измерений

Hidden-tab тест управляет `document.hidden` и отправляет visibility event; это проверка lifecycle, не исследование поведения всех ОС. Frame intervals и long tasks измерены в Chromium с 4× CPU throttle, не равны гарантиям compositor/GPU FPS. Memory checks проверяют cleanup и локальную динамику heap; они не являются математическим доказательством отсутствия любых утечек.
