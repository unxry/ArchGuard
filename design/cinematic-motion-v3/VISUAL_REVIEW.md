# P039.2 visual / motion review

## Исходное состояние

P039.1 завершён, проверен и отправлен как `75d9b9e`: 69 browser checks, 0 failed, 0 JS/console errors; реальные PNG и WebM. Начало P039.2 не прервало предыдущие тесты. Исходный Precision и Cinematic сохранены.

В P039.1 интерактивен Атлас, но Overview-карта — статичный вход. Плоские области слоёв мало отличаются по глубине, короткий edge pulse не связывает направление с target activation. Вход компонентов в основном opacity/translate; связь между сценами слабая. Бренд потерял характер нижнего регистра из публичного Deluxe v1.

## Выбранный язык

Volumetric Architecture и Living Light Connections соединены в одной сцене: стабильные архитектурные платформы объясняют принадлежность, а конечный свет — фактическое направление отношений. Один signature event — сборка модели и последовательное проявление связей — заменяет набор несвязанных декоративных эффектов.

## Review 1 · Artistic direction

Реальный Chromium, 1920×1080: просмотрены initial/assembled Overview, Atlas, active path и Security.

- Построены трёхгранные слои с контактными тенями, скошенные корпуса модулей и единое направление освещения.
- Hero заголовок пересекал отведённую колонку. Размер ограничен по viewport, дополнительное место отдано сцене.
- Усилены торцевые грани, фаски и контактные тени. Фоновая геометрия остаётся спокойной; яркий свет принадлежит выбранному пути.
- Path tracing получил движение камеры по bounds связанной цепочки; выбор слоя согласован с rim/ambient light и incident edges.
- Логотип эволюционирует из public-safe Deluxe v1 mark: возвращён `archguard`, сохранена вложенная геометрия, выделен небольшой AI бейдж. Приложены dark/light SVG и favicon; глобальный бренд репозитория не изменён.

## Review 2 · Interaction & performance

Реальные captures на 1280×800, 1440×900, 1920×1080 и 2560×1440, затем автоматизация сценариев и CPU/heap profile.

- На малом desktop удалены повторяющиеся подписи типов, увеличены основные подписи Overview и исправлено их размещение внутри корпусов. В Atlas основные подписи не менее 12 screen px на целевых размерах.
- Переключение на reduced motion отменяет scopes и прекращает движение; выключенные scopes не остаются в глобальном реестре. Тест ждёт фактического browser media-query event, не опрашивая matches до события. На длинном сценарии такой опрос подавлял change notification в используемом Chromium; event-based проверка проходит.
- Shared SVG переносится через DOM clone с отдельными IDs. Это сохраняет вычисляемый fade и не вызывает CSP-ошибки при сериализации inline styles.
- Replay остаётся доступным при выбранном модуле через общую строку слоёв. Настройки не зависят от того, показана ли карточка выбора.
- Свет получил явную фазу tracing и действительное вычисляемое затухание trail. Rest обозначает конечное спокойное состояние.
- 40/216: слойные кнопки в агрегированном виде отключены; вход — через реальные объёмные кластеры. Возврат Overview восстанавливает фактическую 12-модульную демонстрацию, не выдаёт density fixture за новый проект.
- Узкое окно: сообщение о desktop-разрешении и освобождение скрытого graph. Мобильный layout/graph/motion не разрабатывались согласно последнему дополнению пользователя.

## До / после

| Область | P039.1 | P039.2 | Польза |
|---|---|---|---|
| Overview | Статичная изометрическая иллюстрация-ссылка | Живая модель того же dataset; сборка, выбор слоя/модуля, сохранение контекста | Осмысленная точка входа в архитектуру |
| Atlas | Смещённые плоские полосы, обычные карточки | Платформы с торцами и светом; корпуса с фасками; доменные объёмы | Иерархия слоёв и активной области считывается пространственно |
| Path | До четырёх движущихся точек | Геометрически точный trail, затухание, target activation, ограниченная цепочка, camera fit | Направление и конечные узлы различимы без runtime-иллюзии |
| Evidence | Статичный trace и source | Последовательное раскрытие, keyboard step focus, точная source-line подсветка | Можно сопоставить утверждение с его координатой |
| Desktop | Общий responsive layout | Проверены четыре настольных размера; крупная сцена на больших мониторах | Пространство используется для архитектуры и evidence |
| Motion control | Общий on/off | Full/restrained/off + edge flow + tempo + replay | Пользователь регулирует интенсивность без потери функций |

Новые baseline PNG снимаются из сохранённого P039.1 тем же реальным Chromium. Новые after captures и WebM показывают исполняемый интерфейс, не подставленные кадры. В галерее каждое изображение открывается целиком.

Полноценная production-миграция Models/Runs и научные изменения не входят в этап. Никаких новых detector outputs, confidence scores или AI actions не добавлено.
