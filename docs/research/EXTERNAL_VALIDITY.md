# External validity — OSS annotation seed

OSS improves realism of source organization, dependency distributions and failure modes compared with
controlled synthetic/mutation fixtures. It does not automatically make annotations correct or make
this sample representative of all software systems.

Selection is purposive/convenience-based, restricted to public GitHub projects, detected licenses,
Java/TypeScript majorities, manageable budgets and metadata availability. Eight independent families
provide four repositories per language but mostly libraries/frameworks; deployed applications,
private/enterprise monoliths and other ecosystems remain underrepresented. Several application
candidates were objectively excluded before analysis. GitHub license detection is conservative and
language bytes/repository size are metadata estimates, not architecture characteristics.

All projects retain PARTIAL status. Unresolved/external references, syntax diagnostics, skipped
centrality, omitted nonregular Git entries and test/example source alter the observable graph.
Parsed counts do not prove semantic correctness. Dependency-based context and sampling inherit these
limitations. Equal-count degree terciles need not separate actual coupling values. Source names/paths
are legitimate human context, not predictive V2 inputs. The frozen sample covers only 40 explicit
subject/question pairs, not all repository components; OUT_OF_SCOPE and NOT_ANNOTATED are necessary.

No human annotations have been completed; independent review quality, agreement and adjudication
are unmeasured. No V2 heldout score, real LLM result, calibrated confidence, superiority, significance
or scalability claim exists. V2 artifact remains unchanged and AWAITING_FRESH_HOLDOUT; old synthetic
TEST cannot regain freshness. Dataset families were chosen without V2 performance, and future labels
must remain blind to model/detector/AI results. Threshold-derived structural signals remain a limited
secondary task, separate from architectural quality judgments and the full Hybrid research claim.

Future work requires actual independent annotation, explicit task/review eligibility, conflict
adjudication and a separately frozen evaluation protocol linking corpus/sample/annotation/model
receipts. Only then can fresh evaluation begin. Full Hybrid remains NOT_READY. PROMPT 013 is not started.
