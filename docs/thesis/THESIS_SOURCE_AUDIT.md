## Фактическая глубина верификации

Проверка выполнена по первичным издательским страницам, авторским экземплярам статей и официальной документации. Для 19 указанных DOI дополнительно получены реальные HTTP 200 ответы Crossref с издательскими метаданными; это подтверждает DOI, авторство, заглавие и выходные сведения. Содержательные тезисы сверены с доступными аннотациями и релевантными началами/разделами первичных текстов, а не выведены из одной библиографической записи. Не заявляется прочтение каждой статьи целиком.

`verification_evidence` сохраняет способ проверки каждого источника. Все URL не объявляются повторно открытыми в этом втором проходе. Часть издательских веб-интерфейсов возвращала 403 или timeout; в таких случаях использованы доступные авторские/университетские экземпляры и издательские DOI-депозиты. У `kaufman2012leakage` непосредственно прочитан издательский abstract через Crossref; прямой интерфейс ACM был недоступен. У `vitale2026` доступны arXiv и опубликованный университетский PDF DiVA; прямой запрос PDF дал HTTP 200. Локальные значения хешей удалённых PDF не выдумывались.

Сведения о проверке сайта ArchGuard относятся к чтению первичного локального репозитория и публичных научных артефактов основной задачей. Отдельная HTTP-проверка GitHub URL в настоящем библиографическом проходе не выполнялась. Оригинальные приватные truth, экспертные тексты, намерения конструирования и секреты для литературного аудита не читались.

Описания унифицированы по последовательности «заглавие / сведения об ответственности // издание; год; том/номер; страницы либо идентификатор статьи; DOI; URL и дата обращения».
