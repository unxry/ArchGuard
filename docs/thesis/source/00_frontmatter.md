# ПЕРЕЧЕНЬ СОКРАЩЕНИЙ И ОБОЗНАЧЕНИЙ

API — интерфейс программирования приложений; AST — абстрактное синтаксическое дерево; CFG — граф потока управления; CI — непрерывная интеграция; DEV — данные разработки и выбора решения; DSL — предметно-ориентированный язык; FINAL — отложенная окончательная выборка; IAM — промежуточная архитектурная модель; LLM — большая языковая модель; ORM — объектно-реляционное отображение; OSS — программное обеспечение с открытым исходным кодом; RSS — резидентная память процесса; SCC — сильно связная компонента; SQL — язык структурированных запросов; taint — отслеживаемая зависимость значения от недоверенного источника.

Обозначения метрик: F1 — гармоническое среднее precision и recall; FN, FP, TN, TP — ложно отрицательный, ложно положительный, истинно отрицательный и истинно положительный результаты в пределах явно заданного протокола; P и R — precision и recall. Для архитектурного эксперимента и отдельного Security-эксперимента определения отказа от решения различаются и приведены в соответствующих главах.

Static, Graph, LLM и Hybrid обозначают исследуемые архитектурные каналы и их объединение. Идентификаторы ARCH относятся к архитектурным правилам, SEC — к отдельному расширению анализа безопасности. Состояния UNKNOWN, PARTIAL, POTENTIAL и UNSUPPORTED сохраняются в написании программных контрактов; они не означают доказанную безопасность.
