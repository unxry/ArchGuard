## Зафиксированные расхождения

- **Содержание:** ГОСТ 7.32–2017 §5.4.1 предусматривает отточие, СТУ §4.3.5 прямо запрещает его. Выбрано специальное университетское требование: без отточий.
- **Электронный формат:** СТУ §4.3.1.1 прямо указывает .rtf/.doc. По требованию пользователя основной редактируемый master — DOCX. Прием DOCX точной кафедрой не подтвержден. Нельзя объявлять соответствие legacy-формату на основании одного DOCX; RTF/DOC нужен лишь после проверенного экспорта и приемки.
- **Объем:** СТУ §4.2.3 устанавливает минимум 90 страниц для магистратуры, но не содержит отдельного исключения приложений из этой формулировки. Общий объем и объем до приложений следует сообщить раздельно; конкретная кафедральная трактовка — ADMIN_REQUIRED.
- **Форма задания:** приложение Д к СТУ относится к курсовой работе. Для данной ВКР применима магистерская форма приложения Е П 02.032, страница 31; бакалаврская форма и специалистская форма страницы 30 не подменяют ее.
- **ГОСТ ЕСКД:** ГОСТ Р 2.105–2019 действует, но его собственная область — конструкторские текстовые документы. Его нельзя без кафедрального основания объявить обязательным для всей программной ВКР.
