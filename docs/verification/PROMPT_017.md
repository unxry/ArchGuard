## Prospective arithmetic

SUPPORTED predicts positive and NOT_SUPPORTED predicts negative.
INSUFFICIENT_CONTEXT is abstention; NOT_APPLICABLE is an applicability outcome.
Neither is converted to a negative prediction. TP/FP/TN/FN count definitive
predictions only. Positive/negative abstentions and applicability outcomes are
reported separately and reconcile to all 96 eligible cases.

Precision = TP/(TP+FP); definitive recall = TP/(TP+FN);
definitive F1 = 2TP/(2TP+FP+FN); specificity = TN/(TN+FP);
FPR = FP/(TN+FP); FNR = FN/(TP+FN). A zero denominator returns null.
Definitive coverage = (TP+FP+TN+FN)/96; binary abstention/applicability rates
use 96. Effective recall = TP/50; effective negative correctness = TN/46;
effective correctness = (TP+TN)/96. Counts and denominators are explicit.
