## Frozen diagnostic definitions

The original design is 100 cases / 50 matched pairs, with one MUTATION and one
CONTROL per pair. Each ARCH201–205 rule has ten pairs: five JAVA and five
TYPESCRIPT. Intended mutation direction is INTENDED_MUTATION_POSITIVE; intended
control direction is INTENDED_CONTROL_NEGATIVE. Neither is a human truth label.
No heuristic reconstruction from source is permitted.

The case cross-tab retains all four final human categories. Mutation positive
confirmation, negative contradiction, uncertainty and OOS rates use all 50
mutation members. Control negative confirmation, positive contradiction,
uncertainty and OOS rates use all 50 controls. Stratum denominators similarly
include every original member. Binary agreement alone uses the 96 human
POSITIVE/NEGATIVE cases and explicitly reports four excluded cases. Zero
denominators return null.

Pair categories are mutually exclusive:

- FULLY_CONFIRMED: mutation POSITIVE, control NEGATIVE.
- MUTATION_NOT_CONFIRMED: mutation not POSITIVE, control NEGATIVE.
- CONTROL_NOT_CONFIRMED: mutation POSITIVE, control not NEGATIVE.
- BOTH_NOT_CONFIRMED: mutation not POSITIVE, control not NEGATIVE.

All 50 pairs remain in pair-rate denominators. Independent tags preserve pairs
involving UNCERTAIN or OUT_OF_SCOPE. The complete ordered 4×4 human category
table has mutation first and control second; it imposes no ordinal ranking on
nonbinary values. Rule/operator, language and rule×language summaries are
descriptive, with 10, 25 and 5 pairs respectively. There is no objective validity
threshold and no automatic CONSTRUCTION_VALID assertion.

## Interpretation and boundaries

An intended mutation judged NEGATIVE means its intended violation was not
independently confirmed. A control judged POSITIVE means the matched control
was judged to exhibit the target violation. Neither finding establishes
reviewer error. UNCERTAIN and OUT_OF_SCOPE remain unchanged.

No relabeling, removal, replacement, rebalancing, pair change, operator change,
mutation regeneration, rule-definition change, AI rerun or tuning is allowed.
P017 continues to report frozen AI assessments against all eligible human cases;
there is no filtered replacement F1 or supplemental AI-error analysis. No
Static/Graph effectiveness, V2, Hybrid, Security or ablation is executed.
Provider/network calls and paid execution are zero during analysis; credentials
are not read. Normal Git push is performed only for the explicitly authorized
repository closure.

Private construction/case/pair joins remain Git-ignored, mode 600 in a mode 700
directory. Public outputs contain only aggregate counts, rates, operator/rule
and language summaries, fingerprints, methodology and limitations. They contain
no case/pair IDs, reviewer identities, rationales, notes, evidence or source text.

Full A–L results and completed quality checks will follow the real diagnostic
and append-only result freeze.
